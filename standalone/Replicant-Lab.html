1. Visión general

Replicant Lab separa estación de trabajo, servidor Linux local, repositorios Git y servicios cloud. GitHub es la fuente de verdad del código y de la configuración versionable; los datos, secretos y backups permanecen fuera de Git.

Servicios públicos o 24x7.

5. Docker

Patrón preferido del lab:

GitHub → /opt/apps/<repo> → compose.yml → docker compose up -d

Buenas prácticas: imágenes oficiales cuando proceda, persistencia fuera del contenedor, secretos fuera de Git, puertos mínimos, procesos no-root cuando sea viable y restart: unless-stopped para servicios permanentes.

Arquitectura Nexus

Replicant / LAN
      ↓
192.168.18.220:8083
      ↓
reserva-pistas-nginx
      ↓ red privada Docker
app:8765
      ↓
reserva-pistas-app
      ↓
/app/data ← bind mount → /opt/data/reserva-pistas

El servicio app se construye desde python:3.12-slim, ejecuta python app.py, escucha en 0.0.0.0:8765 dentro del contenedor y corre con UID/GID 1000:1000. Nginx usa nginx:alpine, publica solo 192.168.18.220:8083 y resuelve el backend por el nombre Docker app.

Configuración por entorno

APP_HOST=0.0.0.0
APP_PORT=8765
APP_DATA_DIR=/app/data

Los valores por defecto del código siguen siendo 127.0.0.1, 8765 y ., por lo que el mismo código puede funcionar en otros entornos sin una variante de app.py.

Persistencia

Los ficheros locales viven fuera de la imagen:

credentials.local.json
notifications.local.json
tasks.local.json
telegram.offset.local
telegram.state.local

Se validó la persistencia después de recrear contenedores y el arranque automático después de reiniciar Nexus.

Diferencias Nexus / producción

AspectoNexusDigitalOcean
ObjetivoLab, staging y ejecución controladaProducción 24x7
BackendDockerPython + systemd
ProxyNginx DockerNginx del host
EntradaLAN :8083HTTPS /padel/
Datos/opt/data/reserva-pistas/opt/reserva-pistas
Regla crítica: Nexus puede ejecutar reservas reales, pero no debe ejecutar simultáneamente tareas equivalentes con DigitalOcean. El tasks.local.json vivo de producción debe sincronizarse de forma controlada antes de activar Nexus con el mismo histórico.

Validación

OK build, red privada, HTTP 200, persistencia, usuario no-root, recreación y reboot completo del host.

8. Operación

cd /opt/apps/Reserva-Pistas-UTP
git switch main
git pull
docker compose up -d --build

docker compose ps
docker logs reserva-pistas-app --tail 50
docker logs reserva-pistas-nginx --tail 50

Los servicios usan restart: unless-stopped. Docker Engine los recupera automáticamente después de reiniciar Ubuntu.

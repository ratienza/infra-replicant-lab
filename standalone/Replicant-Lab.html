1. Visión general

Replicant Lab es una infraestructura doméstica de trabajo orientada a desarrollo, pruebas y despliegue de aplicaciones. Se separan estación de trabajo, servidor Linux local, repositorios Git y servicios cloud.

Minimalismo
Pocas piezas y cada una con una función clara.
Fuente de verdad
GitHub para código y configuración versionable.
Persistencia
Datos, backups y secretos fuera de Git.
Ejecución
Docker como capa preferida para servicios.

2. Arquitectura general

GitHub gobierna código y configuración reproducible. Nexus y DigitalOcean ejecutan. Los datos sensibles no se sincronizan automáticamente.

8. Docker y despliegue

  • Imágenes oficiales cuando sea posible.
  • Persistencia fuera del contenedor.
  • Publicar solo los puertos necesarios.
  • Preferir bind explícito a la IP LAN de Nexus.
  • No instalar paneles de gestión sin necesidad real.

10. Seguridad

  • SSH mediante clave pública.
  • UFW activo.
  • Incoming deny / outgoing allow.
  • 22/tcp permitido solo desde 192.168.18.0/24.
  • Actualizaciones automáticas de seguridad activas.
No instalar por defecto: DNS local, reverse proxy, Portainer, Cockpit, Webmin, fail2ban o monitorización compleja mientras no exista una necesidad concreta.

11. Operación diaria

Acceso

ssh nexus
ssh docean

Estado rápido

docker ps
sudo ufw status verbose
sudo ss -tulpn
sudo apt update
apt list --upgradable

Actualizar un proyecto

cd /opt/apps/<proyecto>
git switch main
git pull
docker compose up -d

# 9 de noviembre de 2026 · CryptoWallet V1.7.6

## Consulta unificada de Bit2Me y valoración histórica

CryptoWallet pasó de las compras Wallet a una consulta **secuencial Wallet + Pro con un único «Actualizar Bit2Me»**. Cada ejecución compatible de Pro se presenta para revisión independiente; no hay compras automáticas ni doble contabilización de transferencias entre Wallet y Pro. La operación USDC → BTC conserva su precio ejecutado y utiliza **USDC/USD histórico directo (Kraken)** como referencia de valoración, con fuente y momento. Sin datos suficientes, se exige entrada documentada; nunca se inventa paridad.

## Corrección de visibilidad y continuidad

La V1.7.6 evita que el acceso a la actualización desaparezca al arrancar con privacidad activa: se mantiene visible un bloque seguro para mostrar cifras solo durante la sesión. Cuando la privacidad está desactivada, el panel se despliega, informa de pendientes separados por Wallet y Pro y conserva la operación Pro después de contabilizar una compra recurrente de Wallet.

# 4 de octubre de 2026 · Cartera v2.0.0

La release funcional `v2.0.0` de `ratienza/cartera-estrategica` se publicó desde el PR #27 en `c672eb1cadfcb191aaff6db8aeb1ed783321b692`. Antes de esta actualización documental se comprobó en Nexus el mismo SHA en checkout y etiqueta OCI del contenedor de Cartera, saludable y con HTTP `200` en `:8085`.

Se actualizan la ficha, catálogo, arquitectura, operación, despliegue y portables de Replicant Lab. La cuenta Indexa usa únicamente su API oficial verificada para el saldo, flujos, métricas y diez fondos; se distingue la consulta del cierre efectivo. El refresco es de sesión/recarga o manual, no una tarea autónoma. Se documentan el fallback al último cierre oficial fechado y la prohibición de suplirlo con NAV o proveedores externos.

`cartera-demo.db` es el nombre heredado de la base privada real de Nexus. Esta publicación documental no modifica datos financieros, configuración de seguridad ni el contenedor de Cartera. Las notas de septiembre y [RL-CE-DOC-001](../encargos/RL-CE-DOC-001.md) son históricas y quedan conservadas.

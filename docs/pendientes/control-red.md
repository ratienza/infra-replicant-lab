# Pendientes · Control de Red

## Protección previa

Hacer backup antes de intervenir.

## Separación de datos

- Separar inventarios, snapshots y datos operativos reales del código Git.
- Mantener únicamente ejemplos anonimizados en el repositorio.

## App Launch

La tarjeta existe solo en el App Launch de Nexus y abre la ficha técnica. No debe presentarse como runtime web ni añadirse al catálogo público mientras la herramienta siga ejecutándose localmente en Replicant.
